# The Tinikling Method: High-Performance Rhythm Agility Framework

The Tinikling Method is an open-source sports science framework that adapts traditional rhythmic patterns—originating from the Philippine dance Tinikling, alongside West African, Afro-Caribbean, and Hispanic styles—into elite athletic footwork and team coordination drills for sports like soccer and rugby.

## 🚀 The Vision: AI-Powered Biomechanical Analytics
While this repository currently hosts structural documentation and foundational math scoring engines, our upcoming roadmap incorporates **Computer Vision Edge AI** architectures designed for the NVIDIA Inception Program. 

By leveraging **NVIDIA TensorRT** and **DeepStream pipelines**, the system will analyze standard 60fps video to track human ankle keypoints relative to moving boundary poles. It calculates critical sports performance vectors in real-time:
* **Ground Contact Time (GCT):** Velocity of foot strikes inside and outside the rhythm zone.
* **Cognitive Load Latency:** Measuring changes in cadence when external sport-specific elements (balls/passes) are introduced.
* **Interpersonal Sync Index:** Phase-alignment algorithms tracking synchronization between multi-athlete defensive or attacking units.
