# Security Policy & Vulnerability Protocol

## 1. Supported Software Versions
We actively provide security patches and telemetry isolation audits for the following baseline versions:

| Version | Supported |
| :--- | :--- |
| 1.2.x | 😄 Yes |
| 1.1.x | ⚠️ Critical Fixes Only |
| < 1.0.0 | ❌ No |

## 2. Reporting a Vulnerability
**Do not open public GitHub Issues for security bugs or data leaks.** 

If you discover a vulnerability regarding keypoint spoofing, data serialization leaks, or unauthorized local frame capture on edge units, please report it via encrypted channels:
1. Email our core compliance response desk at `security@yourmethoddomain.internal`.
2. Include a detailed proof-of-concept description alongside hardware logs (e.g., NVIDIA Jetson logs or TensorRT build flags).

We will confirm receipt of your report within **48 hours** and provide a tracked resolution timeline before public coordinate updates are staged.
